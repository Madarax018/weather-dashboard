# Weather Dashboard

Browser-based weather dashboard using the free Open-Meteo API.

Open index.html in a browser with internet access.

## Installation

Clone the repository:

```bash
git clone https://github.com/Madarax018/weather-dashboard.git
cd weather-dashboard
```

## Running the project

Open `index.html` in a modern web browser.

## Automated testing

Run the tests locally:

```bash
python -m unittest discover -s tests -v
```

GitHub Actions runs these tests automatically when
changes are pushed or a pull request is opened.
